# Draft migration boundary

This directory is the boundary between the editorial Markdown draft and the normalized graph database.

The current seed is deliberately conservative: it records the 42 working entries as presentation-level cards without inventing claims or sources that are not present in the draft.

Next migration stages:

1. extract card prose into structured claims;
2. identify first-class cases;
3. attach primary/secondary sources;
4. create competing interpretations where the draft marks material as contested;
5. create open research questions where the draft identifies missing evidence or unresolved issues.

Do not treat a missing source as evidence that a claim is false. It means the migration has not yet attached evidence.
