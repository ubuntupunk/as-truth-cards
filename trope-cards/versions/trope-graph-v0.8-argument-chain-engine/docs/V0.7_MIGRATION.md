# v0.7 Migration

## Migration strategy

v0.7 is additive. Existing cards, claims, sources, cases, interpretations and generic relationships remain intact.

Run:

```text
0002_claim_decomposition.sql
```

after the existing v0.x migrations.

## New tables

1. `inference_steps`
2. `inference_premises`
3. `inference_conclusions`
4. `claim_relations`

## Backfill

No automatic backfill should infer argument structure from existing card prose.

Existing `claim_sources` remain source-to-claim evidence links.

Existing generic graph relationships remain available.

Researchers can progressively decompose important cards into inference chains.

## Suggested backfill order

1. Jesus Was a Zionist
2. Jesus Was a Palestinian
3. Jesus Is a Muslim
4. Canaanite Card
5. Land of the Children of Israel
6. Chronology

These form a useful test cluster because they contain explicit questions of retrospective identity, chronology and category transfer.

## Rollback

Drop the four new tables in reverse dependency order:

```sql
DROP TABLE IF EXISTS inference_conclusions;
DROP TABLE IF EXISTS inference_premises;
DROP TABLE IF EXISTS inference_steps;
DROP TABLE IF EXISTS claim_relations;
```
