# Trope Graph v0.6 migration

## Purpose

Apply the Identity Retrospection cluster to the existing v0.5 corpus without rewriting the existing 45-card corpus.

## Additions

- Mechanisms: `RETROSPECTIVE_IDENTITY`, `ANACHRONISM`, `ESSENTIALISM`
- Card: `jesus-was-a-zionist`
- Card: `canaanite-card`
- Identity-retrospection claims and typed relationships

## Existing cards expected

The migration assumes v0.5 already contains:

- `jesus-is-a-muslim`
- `jesus-was-a-palestinian`
- `the-land-of-the-children-of-israel`
- `chronology`
- `jews-are-not-white`
- `jews-are-white`
- `white-european-settlers`
- `settler-colonialism`
- `balfour-colonial-origins`

If any slug is absent, relationship insertion should be skipped or reported by the seed validator rather than silently creating an orphan edge.

## Editorial note

The Canaanite card documents a modern argument and decomposes it into separately testable historical claims. It does not encode the proposition that Palestinians are identical to ancient Canaanites, nor that ancient Canaanite continuity negates Jewish historical connection.
